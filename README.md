# Riddhi Thakkar — Full-Stack Developer Portfolio

A modern, responsive personal portfolio website for **Riddhi Thakkar**, a Full-Stack Developer working across frontend, backend, databases, cloud infrastructure, and AI-powered applications.

## About

The portfolio is designed as a living professional profile for recruiters, hiring managers, and engineering teams. It highlights Riddhi's experience, technical stack, and contact information, while keeping the projects section ready for future additions.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive design
- CSS animations and scroll reveal effects
- Google Fonts
- GitHub Pages

### Core Technologies Featured

**Languages:** Python, TypeScript, JavaScript, Java, Go, C++, SQL  
**Frontend:** React.js, Next.js, Tailwind CSS, Material UI  
**Backend:** FastAPI, Node.js, Express.js, REST, GraphQL, WebSockets  
**Databases:** PostgreSQL, MongoDB, Redis, Pinecone, Weaviate, pgvector, Neo4j  
**Cloud / DevOps:** AWS, Docker, Kubernetes, Terraform, GitHub Actions, CI/CD, Linux  
**AI / GenAI:** OpenAI API, Claude API, LangChain, LangGraph, LlamaIndex, RAG, embeddings, AI evaluations

## Features

- Fully responsive desktop, tablet, and mobile layout
- Developer-focused modern visual design
- Smooth navigation and scrolling
- Scroll-based reveal animations
- Accessible semantic HTML
- SEO metadata and Open Graph metadata
- GitHub and LinkedIn links
- Direct email contact
- Projects section prepared for future work

## Local Development

No build system is required.

1. Clone the repository.
2. Open `index.html` in a browser, or serve the directory with a local static server.
3. Edit `index.html`, `style.css`, and `script.js` as needed.

## Deployment

The site is designed for static hosting and can be deployed directly with **GitHub Pages** from the `main` branch.
